# Windows Admin Scripts

PowerShell scripts and automation tools for Windows Administration, IT Operations and Infrastructure Support.

## Technologies

- PowerShell
- Windows 10/11
- Windows Server
- Active Directory
- Microsoft 365
- Infrastructure Monitoring

## Scripts

### Get-DiskSpace.ps1

Displays disk usage information.

### Check-Services.ps1

Checks critical Windows services.

### Get-SystemInfo.ps1

Collects basic workstation and server information.
